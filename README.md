# NIAC Project: Satellite Debris Detection via Soliton Wake Model

A C++ simulation framework for studying the detection of solitons generated by orbital debris by mLPs on a cubesat. This project implements orbital mechanics, debris sampling, and detection algorithms to evaluate the feasibility of passive debris detection methods.

## Overview

This project simulates:
- **Satellite Orbit Propagation**: Two-body problem propagation in Earth-Centered Inertial (ECI) frame
- **Debris Sampling**: Random generation of debris samples around satellite trajectories
- **Soliton Wake Model**: Conical wake expansion model for detecting debris passing through satellite wakes
- **Detection Simulation**: Monte Carlo analysis of debris detection probability based on soliton intersections
- **Sensor Configuration**: Multi-sensor systems with configurable boom angles and detection frequency

## Key Classes

### Orbit
Handles orbital mechanics and two-body propagation:
- Converts between orbital elements (a, e, i, ω, Ω, ν) and Cartesian coordinates (x, y, z, vx, vy, vz)
- Implements 2-body propagation with configurable time steps
- Computes orbital period and other classical orbital parameters

### Satellite
Manages satellite dynamics, sensors, and detection logic:
- Maintains satellite orbit and state vectors
- Manages sensor boom geometry and orientation
- Detects debris based on soliton wake intersection
- Saves detection results with metadata

### Soliton
Models the conical wake structure behind the satellite:
- Expands linearly with time from satellite position
- Parameterized by cone angle, cone height, and velocity multiplier
- Determines if a point/debris is within the expanding soliton shell

### Debris
Represents orbital debris objects:
- Holds state vectors (position, velocity)
- Checks intersection with soliton wakes
- Tracks detection events and timing

## Building the Project

### Prerequisites
- C++17 or later
- Eigen 5.0.0 (included in `include/eigen-5.0.0/`)
- OpenMP (optional, for parallel processing)
- CMake or Make

```bash
g++ -O3 -fopenmp -std=c++17 \
  -Iinclude \
  src/*.cpp \
  -o bin/runner
```

## Running Simulations

### Basic Simulation
```cpp
// Create satellite with orbit
Orbit o;
Eigen::VectorXd OE(6);
OE << 7121, 0.063, 135, 0, 0, 45;  // a(km), e, i(°), ω(°), Ω(°), ν(°)
o.set_OE(OE);

Satellite sat;
sat.set_orbit(o);

// Configure sensors and soliton
Eigen::VectorXd boom_angles(8);
boom_angles << 90*M_PI/180, 0, 90*M_PI/180, 0, 90*M_PI/180, 0, 90*M_PI/180, 0;
sat.set_sensor_vectors(boom_angles);

Eigen::Vector3d soliton_params;
soliton_params << 30.0 * M_PI / 180.0, 0.5, 1.5;  // cone angle(rad), height(km), velocity multiplier
sat.set_soliton_params(soliton_params);

// Run detection simulation
sat.detection_sim(10000, 1.0, 10.0);  // num_samples, search_radius_km, final_time_s
```

## Configuration Parameters

### Satellite Orbit
- `a`: Semi-major axis (km) - default ~7121 km (LEO)
- `e`: Eccentricity - default 0.063
- `i`: Inclination (°) - default 135°
- `ω`: Argument of perigee (°) - default 0°
- `Ω`: Right ascension of ascending node (°) - default 0°
- `ν`: True anomaly (°) - default 45°

### Soliton Wake Model
- `cone_angle`: Opening angle of wake cone (rad) - default 30° (0.524 rad)
- `cone_height`: Cone height extension (km) - default 0.5 km
- `velocity_multiplier`: Soliton velocity relative to debris velocity - default 1.5

### Detection Parameters
- `detection_freq`: Sensor sampling frequency (Hz) - default 10 kHz
- `num_samples`: Number of debris samples to generate - typical 10,000
- `search_radius`: Debris sampling radius around satellite (km) - default 1.0 km
- `final_time`: Simulation duration (s) - default 10 seconds
